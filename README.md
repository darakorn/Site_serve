# สำรวจหน้างาน (Site Survey)

เว็บแอปสำหรับมือถือ ใช้ตอนไปสำรวจหน้างาน: วัดผนังทีละด้าน ใส่ประตู/หน้าต่าง ถ่ายรูปแนบกับผนัง วาดเส้นระยะบนรูป แล้วได้แปลนห้องพร้อมรายงานทันที

ไม่ต้องติดตั้งอะไร ไม่มี build step เป็น HTML/CSS/JavaScript ล้วน ข้อมูลและรูปเก็บในเครื่อง (IndexedDB) ใช้งานออฟไลน์ได้

## ฟีเจอร์

หน้าจอแอปเป็นภาษาอังกฤษ (ตั้งแต่ 1.0.14)

- โปรเจกต์ → ห้อง → ผนัง
- เลือกหน่วยวัดระยะต่อโปรเจกต์: มม., ซม. หรือ ม. (ใช้ทั้งกรอกและแสดงในแปลน/รายงาน/DXF)
- สร้างห้องสี่เหลี่ยมจาก กว้าง × ยาว หรือไล่ใส่ผนังทีละด้าน (ความยาว + มุมเลี้ยว ขวา/ซ้าย 90°, 45° หรือกำหนดองศาเอง)
- แปลนวาดสดตามที่กรอก มีเส้นบอกระยะ ชื่อมุม (A, B, C…) และเลขผนัง แตะผนังในแปลนเพื่อไปที่ผนังนั้น
- แจ้งเตือนถ้าห้องไม่ปิด และกดเพิ่มผนังปิดห้องให้อัตโนมัติได้
- ประตู / หน้าต่าง / ช่องเปิด: ระยะจากมุม, กว้าง, สูง
  - ประตู: บานเปิด, บานเลื่อน, บานสวิง 2 ทาง · 1–4 บาน
  - หน้าต่าง: บานเปิด, บานเลื่อน, บานกระทุ้ง · 1–6 บาน หรือช่องหน้าต่างเฉยๆ (ไม่มีบาน)
- ชนิดผนัง: ก่ออิฐ (ทึบดำ), ผนังเบา (เส้นขอบ), กระจก — วาดใหม่หรือเปลี่ยนทีหลังได้ (DXF layer `Wall`, `Partition`, `Glass`)
- ความหนาผนังแยกแต่ละผนัง แปลนวาดหนาตามจริง ประตูมีวงกบ
- คำนวณพื้นที่พื้น ความยาวรอบห้อง และพื้นที่ผนังสุทธิ (หักช่องเปิด) เมื่อใส่ความสูงฝ้า
- ถ่ายรูปหรือเลือกจากคลัง แนบกับผนังหรือภาพรวมห้อง วาดเส้นระยะ ↔ ข้อความ และเขียนด้วยปากกาบนรูป (7 สี)
- ส่งออกแปลนเป็น PNG (แชร์ไป LINE ได้บนมือถือ)
- เสาเหลี่ยมหรือเสากลม: ชิดมุม ติดผนัง หรือเสาอิสระวางได้ทุกที่ในแปลน
- ประตูบานเลื่อนเลือกเปิดกลาง เลื่อนซ้าย หรือเลื่อนขวา
- เสาอิสระบอกระยะจากผนังอัตโนมัติ และเครื่องมือ ↔ Dimension ใส่เส้นบอกระยะเองได้ทุกที่
- ผนังโค้ง (ใส่ระยะโค้งจากเส้นตรงมุมถึงมุม หรือรัศมี R, ปุ่มครึ่งวงกลม), ห้องวงกลมจากรัศมี, แบ่งผนัง และแทรกผนังภายหลัง
- ป้ายประตู/หน้าต่าง D1, W1… แก้ชื่อได้ แตะในแปลนเพื่อไปแก้ ประตูเลือกเปิดเข้า/ออก
- ย่อรายการผนังเหลือผนังละบรรทัด
- วัดระยะประตู/หน้าต่างต่อจากบานก่อนหน้าได้
- วาดเส้นตรง สี่เหลี่ยม วงกลม ลงในแปลน (เคาน์เตอร์ ฯลฯ) พร้อมชื่อและขนาด — DXF layer `Furniture`
- ลบผนังแล้วผนังอื่นอยู่ที่เดิม ผนังที่ลบเป็นเส้นประให้ใส่ผนังกลับ แบ่ง หรือเอาออกภายหลัง
- ย้อนกลับ / ทำซ้ำ การแก้ในห้อง และคัดลอกห้อง
- แก้ไขในแปลนด้วยการลาก: ย้ายประตู หน้าต่าง เสา สิ่งของ, ยืด/หด/หมุนผนังจากปลายด้านไหนก็ได้ เลื่อนผนังทั้งเส้นด้วยจุดกลาง, ลบสิ่งที่เลือกในแปลนด้วยปุ่ม Delete, วาดผนังใหม่ต่อจากผนังล่าสุด พร้อม Snap
- ส่งออกแปลนเป็น DXF สำหรับ AutoCAD / ZWCAD / LibreCAD / SketchUp ทีละห้องหรือทุกห้องในไฟล์เดียว หน่วย มม. layer `Wall`, `Door`, `Window`, `Opening`, `Column` เป็นรูปปิดพร้อม extrude เป็น 3D (ผนังและเสาสูงเท่าฝ้า) สัญลักษณ์บานใน `Door-Symbol` / `Window-Symbol` ระยะใน `Dim` ข้อความใน `Text`
- รายงานรวมทุกห้อง: แปลน ตารางผนัง และรูปพร้อมคำอธิบาย พิมพ์หรือบันทึกเป็น PDF
- สำรอง/นำเข้าโปรเจกต์เป็นไฟล์ `.siteserve` (รวมรูป) ไว้ย้ายเครื่อง

## วิธีวัด

ยืนในห้อง เริ่มที่มุม A แล้วไล่วัดผนังวนตามเข็มนาฬิกา (ห้องอยู่ทางขวามือ) ห้องสี่เหลี่ยมทั่วไปเลี้ยวขวา 90° ทุกมุม มุมที่ยื่นเข้ามาในห้อง (เช่นห้องรูปตัว L) ให้เลี้ยวซ้าย

## รันบนเครื่อง

```bash
python3 server.py
```

เปิด http://localhost:8080 — ใช้ Python 3 อย่างเดียว ไม่ต้องติดตั้งอะไรเพิ่ม (ตัวเลือก: `--port 8080`, `--bind 127.0.0.1`, `--data /path/to/DATA`)

`server.py` เสิร์ฟแอปและรับปุ่ม **อัปโหลดเข้า server** ที่หน้าโปรเจกต์ ไฟล์จะไปอยู่ที่

```
DATA/<วันที่สำรวจ>/<ชื่อโปรเจกต์>/
  <โปรเจกต์>.siteserve        ไฟล์สำรอง (นำเข้าแอปได้)
  <โปรเจกต์> all rooms.dxf
  <ห้อง>/plan.png
  <ห้อง>/plan.dxf
  <ห้อง>/photos/01 Wall 1 · note.jpg
  <ห้อง>/photos/01 Wall 1 · note (annotated).jpg
```

อัปโหลดซ้ำจะเขียนทับไฟล์ชื่อเดิม (ไฟล์ของรูปที่ลบไปแล้วยังค้างอยู่) ถ้าไม่ได้ใส่วันที่สำรวจจะใช้วันที่อัปโหลด server ไม่มีระบบ login ให้เปิดเฉพาะในวง LAN หรือหลัง `tailscale serve` เท่านั้น ส่วน GitHub Pages อัปโหลดไม่ได้

`python3 -m http.server 8080` ก็ยังใช้เปิดแอปได้ แต่จะไม่มีอัปโหลด

เปิด http://localhost:8080

## ใช้บนมือถือ

- **ทดสอบในวง Wi-Fi เดียวกัน:** รันคำสั่งด้านบน แล้วเปิด `http://<IP เครื่องคอม>:8080` บนมือถือ ถ่ายรูปได้ปกติ แต่โหมดออฟไลน์/ติดตั้งเป็นแอปต้องใช้ HTTPS
- **ใช้งานจริง:** เปิด GitHub Pages ของ repo นี้ (Settings → Pages → Deploy from branch `main`) จะได้ลิงก์ HTTPS แล้วกด "เพิ่มลงหน้าจอหลัก" ในเบราว์เซอร์มือถือ จะใช้ได้เหมือนแอปและทำงานออฟไลน์

> ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์จะหาย ควรกด "สำรองโปรเจกต์เป็นไฟล์" หลังจบงานแต่ละที่

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บหลัก |
| `js/app.js` | หน้าจอ การนำทาง และการจัดการข้อมูล |
| `js/plan.js` | คำนวณรูปทรงห้องจากผนัง และวาดแปลนเป็น SVG |
| `js/dxf.js` | ส่งออกแปลนเป็นไฟล์ DXF |
| `js/tools.js` | ลาก ย้าย ยืด วาดผนัง/สิ่งของในแปลน และ Snap |
| `js/zoom.js` | ซูมเฉพาะแปลน |
| `js/camera.js` | กล้องในแอป (ถ่ายรูปโดยไม่ต้องเปิดแอปกล้อง) |
| `js/annotate.js` | บีบอัดรูป และหน้าวาดเส้นระยะบนรูป |
| `js/db.js` | เก็บข้อมูลใน IndexedDB |
| `server.py` | เสิร์ฟแอปและรับอัปโหลดเข้า `DATA/` |
| `sw.js` | Service worker สำหรับใช้งานออฟไลน์ |

## ออกเวอร์ชันใหม่

ทุกครั้งที่แก้แล้วจะปล่อยใช้ ให้ขยับเลขเวอร์ชัน (1.0.1 → 1.0.2 → …) สามที่ให้ตรงกัน

1. `APP_VERSION` ใน `js/app.js` (แสดงที่ล่างหน้าแรกของแอป)
2. `CACHE` ใน `sw.js` เช่น `site-survey-1.0.2` (ทำให้มือถือโหลดไฟล์ชุดใหม่)
3. เพิ่มหัวข้อใหม่ใน `CHANGELOG.md`

แล้ว commit และติด tag เช่น `git tag v1.0.2 && git push origin main v1.0.2`
