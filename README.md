# สำรวจหน้างาน (Site Survey) — v1

เว็บแอปสำหรับมือถือ ใช้ตอนไปสำรวจหน้างาน: วัดผนังทีละด้าน ใส่ประตู/หน้าต่าง ถ่ายรูปแนบกับผนัง วาดเส้นระยะบนรูป แล้วได้แปลนห้องพร้อมรายงานทันที

ไม่ต้องติดตั้งอะไร ไม่มี build step เป็น HTML/CSS/JavaScript ล้วน ข้อมูลและรูปเก็บในเครื่อง (IndexedDB) ใช้งานออฟไลน์ได้

## ฟีเจอร์

- โปรเจกต์ → ห้อง → ผนัง
- สร้างห้องสี่เหลี่ยมจาก กว้าง × ยาว หรือไล่ใส่ผนังทีละด้าน (ความยาว + มุมเลี้ยว ขวา/ซ้าย 90°, 45° หรือกำหนดองศาเอง)
- แปลนวาดสดตามที่กรอก มีเส้นบอกระยะ ชื่อมุม (A, B, C…) และเลขผนัง แตะผนังในแปลนเพื่อไปที่ผนังนั้น
- แจ้งเตือนถ้าห้องไม่ปิด และกดเพิ่มผนังปิดห้องให้อัตโนมัติได้
- ประตู / หน้าต่าง / ช่องเปิด: ระยะจากมุม, กว้าง, สูง
- คำนวณพื้นที่พื้น ความยาวรอบห้อง และพื้นที่ผนังสุทธิ (หักช่องเปิด) เมื่อใส่ความสูงฝ้า
- ถ่ายรูปหรือเลือกจากคลัง แนบกับผนังหรือภาพรวมห้อง วาดเส้นระยะ ↔ และข้อความบนรูป
- ส่งออกแปลนเป็น PNG (แชร์ไป LINE ได้บนมือถือ)
- รายงานรวมทุกห้อง: แปลน ตารางผนัง และรูปพร้อมคำอธิบาย พิมพ์หรือบันทึกเป็น PDF
- สำรอง/นำเข้าโปรเจกต์เป็นไฟล์ `.json` (รวมรูป) ไว้ย้ายเครื่อง

## วิธีวัด

ยืนในห้อง เริ่มที่มุม A แล้วไล่วัดผนังวนตามเข็มนาฬิกา (ห้องอยู่ทางขวามือ) ห้องสี่เหลี่ยมทั่วไปเลี้ยวขวา 90° ทุกมุม มุมที่ยื่นเข้ามาในห้อง (เช่นห้องรูปตัว L) ให้เลี้ยวซ้าย

## รันบนเครื่อง

```bash
python3 -m http.server 8080
```

เปิด http://localhost:8080

## ใช้บนมือถือ

- **ทดสอบในวง Wi-Fi เดียวกัน:** รันคำสั่งด้านบน แล้วเปิด `http://<IP เครื่องคอม>:8080` บนมือถือ ถ่ายรูปได้ปกติ แต่โหมดออฟไลน์/ติดตั้งเป็นแอปต้องใช้ HTTPS
- **ใช้งานจริง:** เปิด GitHub Pages ของ repo นี้ (Settings → Pages → Deploy from branch `main`) จะได้ลิงก์ HTTPS แล้วกด "เพิ่มลงหน้าจอหลัก" ในเบราว์เซอร์มือถือ จะใช้ได้เหมือนแอปและทำงานออฟไลน์

> ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์จะหาย ควรกด "สำรองโปรเจกต์เป็นไฟล์" หลังจบงานแต่ละที่

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บหลัก |
| `js/app.js` | หน้าจอ การนำทาง และการจัดการข้อมูล |
| `js/plan.js` | คำนวณรูปทรงห้องจากผนัง และวาดแปลนเป็น SVG |
| `js/annotate.js` | บีบอัดรูป และหน้าวาดเส้นระยะบนรูป |
| `js/db.js` | เก็บข้อมูลใน IndexedDB |
| `sw.js` | Service worker สำหรับใช้งานออฟไลน์ |
